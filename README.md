### 👋 The short version
I take messy data, find the pattern hiding in it, and turn it into something a decision-maker can act on. I care less about fancy models than about whether the answer was *useful*.

### 🧠 How I work
```python
class Devansh:
    role = "Data Analyst"
    stack = ["SQL", "PostgreSQL", "Power BI", "DAX",
             "Python", "Pandas", "NumPy", "scikit-learn"]

    def approach(self, problem):
        question = self.define_the_real_question(problem)
        data     = self.clean(self.collect(question))
        insight  = self.analyze(data)
        return self.explain_in_plain_english(insight)
```

### 🔥 Opinions I'll defend
- A model with 95% accuracy that nobody can explain is worse than a simple one people trust.
- Cleaning data is the real job. Modeling is the reward.
- If the insight needs a 10-minute explanation, the chart is wrong.
